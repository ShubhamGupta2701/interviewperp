DSA: Binary Search and Its Invariants

A reliable way to search ordered data—and to recognize the broader “binary search on the answer” pattern.

1. Core concepts

  • Binary search operates on a sorted range and repeatedly discards half of the remaining candidates.
  • An invariant is a condition that remains true at every loop iteration.
  • For a lower bound, the goal is the first index i where a[i] ≥ target.
  • “Search on the answer” applies the same idea to a monotonic yes/no predicate, even when the answer is not an array index.

2. Important definitions and algorithm

Time: O(log n) comparisons. Space: O(1) iteratively.
lo = 0, hi = n                 // search [lo, hi)
while lo < hi:
    mid = lo + (hi - lo) // 2  // avoids lo + hi overflow
    if a[mid] < target:
        lo = mid + 1
    else:
        hi = mid
return lo                       // first position with a[i] ≥ target

The half-open interval [lo, hi) makes the loop condition and empty-range behavior explicit. At termination, lo == hi.

3. Teaching explanation

Ask students to state what each boundary means before writing code. For lower bound, every index before lo is known to be too small, while every index at or after hi is still a possible answer. The midpoint determines which fact can be strengthened; the code is simply the mechanical preservation of that invariant.

4. Examples

Example 1 — Exact lookup.

In [2, 5, 8, 12, 17], searching for 12 checks the middle, then narrows to the right-side candidate. It finishes in logarithmic time.

Example 2 — Insertion point.

For [1, 3, 3, 7] and target 3, lower bound returns index 1, the first valid position—not merely any matching index.

Example 3 — Search on the answer.

To find the minimum shipping capacity that completes packages in D days, ask “can capacity x finish in D days?” The predicate is false, false, then true as x increases, so binary search finds the first true capacity.

5. Misconceptions and exam points

  • “Sorted” means strictly increasing. Duplicates are valid; choose lower or upper bound according to the requirement.
  • Midpoint is always (lo + hi) / 2. In fixed-width integer languages, use lo + (hi - lo) / 2 to avoid overflow.
  • Every binary-search problem gives an array. The essential requirement is a monotonic predicate over an ordered search space.
  • State the interval convention, prove the invariant, and explain why the interval shrinks; these are frequent interview follow-ups.

6. Practice questions

Q1. What does lower bound return in [1, 2, 2, 4] for target 2?

Answer: Index 1, the first index whose value is at least 2.

Q2. Why is binary search O(log n)?

Answer: Each comparison removes roughly half of the remaining candidates.

Q3. What property is required for “search on the answer”?

Answer: A monotonic feasibility predicate: once true (or false), it stays true (or false) in one direction.

Professor's 60-second recap: Binary search is an invariant-preserving boundary search. Define the candidate interval, choose a monotonic question, shrink the interval every iteration, and return the boundary that the problem asks for.
